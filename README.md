# Noether Labs · GitHub configuration

This is the organization-wide GitHub configuration repository for [Noether Labs](https://github.com/noetherlabs), not a product repository. GitHub uses `profile/README.md` as the organization's public profile and may use the templates here as defaults for repositories that do not define their own.

We build and evaluate research software for sensing, estimation and closed-loop control in precision optical systems.

## Research

- [Noether AO](https://github.com/noetherlabs/noether-ao) — differentiable adaptive-optics simulation, controller comparisons, noise, delay and fault studies.
- [ProbeBench](https://github.com/noetherlabs/probebench) — sequential optical calibration and measurement selection under photon budgets.
- [Noether Worlds](https://github.com/noetherlabs/worlds) — reduced-order optical-link control, runtime assurance and hardware-interface contracts.

The published experiments are simulation-based. They do not establish hardware, on-sky or deployed performance. See each project's results and limitations before interpreting numerical claims.

## Repository contents

- [`profile/README.md`](profile/README.md) — public GitHub organization profile.
- [`CONTRIBUTING.md`](CONTRIBUTING.md) — shared contribution guidance; project-specific instructions take precedence.
- [`CODE_OF_CONDUCT.md`](CODE_OF_CONDUCT.md) — expectations for contributors.
- [`.github/ISSUE_TEMPLATE/`](.github/ISSUE_TEMPLATE/) and [`.github/PULL_REQUEST_TEMPLATE.md`](.github/PULL_REQUEST_TEMPLATE.md) — default templates when an individual repository does not provide its own.

Licensing is defined separately in each project. This configuration repository does not make unlicensed research code open source.
