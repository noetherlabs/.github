# Noether Labs

Research software for optical sensing and control.

- [Noether AO](https://github.com/noetherlabs/noether-ao) — Differentiable adaptive optics and controller benchmarking.
- [ProbeBench](https://github.com/noetherlabs/probebench) — Optical calibration and measurement selection under photon budgets.
- [Noether Worlds](https://github.com/noetherlabs/worlds) — Optical-link control and runtime assurance.
