# Contributing

Thank you for your interest in Noether Labs.

This repository holds shared GitHub organization configuration. For scientific software contributions, open issues and pull requests in the relevant [project repository](https://github.com/noetherlabs). A project's own contribution and security policies take precedence over these defaults.

## Before opening an issue

- Check existing issues and documented limitations.
- Include a minimal reproduction, commands, configuration, expected and observed behavior, environment and relevant logs.
- For scientific discrepancies, identify the experiment, metric, units, random seeds and source revision.
- Do not post secrets, personal information or undisclosed security vulnerabilities in public issues.

## Pull requests

1. Explain the problem and the intended behavioral change.
2. Keep the change scoped; include tests or a reproducible verification procedure.
3. Preserve raw evidence and provenance when changing experiments or reported results.
4. Report failures and regressions, not only favorable outcomes.
5. Link the relevant issue, study protocol or design discussion.

See each project's README, `CONTRIBUTING.md`, and licensing terms before submitting changes.
