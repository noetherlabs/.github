# Contributing to noether

Thank you for your interest in contributing to noether!

## Getting Started

1. File issues using our [bug report template](.github/ISSUE_TEMPLATE/bug_report.md) or create a discussion
2. Fork the repository and create a feature branch
3. Make your changes and test them
4. Submit a pull request using our [PR template](.github/PULL_REQUEST_TEMPLATE.md)

## Code Style

Please follow the coding standards and conventions used in the repository. Refer to `.github` templates for PR and issue guidelines.

## Questions?

Feel free to reach out via team@noether.ai
